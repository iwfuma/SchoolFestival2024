#  学園祭（2024）開発備忘録

このリポジトリは、2024年学園祭で作成したプロジェクトをベースに、**ReactとGitHubを用いて再構築したバージョン**です。

元のオリジナルファイルは `original-2024` ブランチに保管しています。  

---

2024年学園祭で作成したプロジェクトの記録用メモ
- フロントエンドフレームワークを活用する  
- GitHubを使ってチーム開発・履歴管理をする  
- 最初に**設計書（画面遷移図、DB設計など）を作る**  
- ファイル・フォルダ構成を整理して分かりやすくする  
- コミットメッセージや開発ルールをチームで統一する
- **タスクを明確に分担し、締切を設定**する


## 反省点
- フレームワークを使用せず、HTML/CSS/JSをベタ書きした
- GitHubを使わなかったため、共同作業が困難だった  
- 設計書を作らなかったので、誰が何を作っているか曖昧だった  
- ファイル名や命名がバラバラで読みづらかった  
- 半年間学んだことを、うまく活かしきれなかった
- コーディングについては妥協した部分もあり、**全員がもう少し前向きに関わっていれば、より良い成果物が作れたはず**

### パスワードについて

パスワードなどの機密情報は、ローカル環境では `.env` ファイルに記述して利用します。  
`.env` ファイル自体は `.gitignore` に追加し、Git リポジトリにはコミットしないでください。

また、チームで共有する必要がある固定パスワードは、リポジトリや `.env` ファイルを直接共有するのではなく、
パスワードマネージャーやセキュアな共有手段など、別の方法で共有してください。

> ※本リポジトリでは学習・検証用のため、便宜上 `.env` を含めています。
